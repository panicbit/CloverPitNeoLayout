# CloverPit Neo Layout

This mod adds support for the [Neo keyboard layout](https://www.neo-layout.org/) to [CloverPit](https://store.steampowered.com/app/3314790/CloverPit/).

## Installation

1. First time only: Copy the contents of the [BepInEx zip][BepInExZip] into the CloverPit installation folder (usually `C:/Program Files (x86)/Steam/steamapps/common/CloverPit`)
2. Copy the contents of the [latest CloverPitNeoLayout.zip][LatestRelease] into the `BepInEx/Plugins` folder inside of the CloverPit installation folder

[BepInExZip]: https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.4/BepInEx_win_x64_5.4.23.4.zip
[LatestRelease]: https://github.com/panicbit/CloverPitNeoLayout/releases/latest

## Usage

Simply select the keyboard layout in the options.
